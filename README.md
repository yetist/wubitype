# 五笔 98 打字练习

用 GTK4 写的五笔字型 98 版打字练习器。按 98 版码表出题，实时判定编码，统计速度、准确率与错题，并配有一张可高亮当前按键的虚拟键盘。

## 功能

- **题组练习**：单字、词组、混合（70% 单字 + 30% 词组）。
- **键位专项**：按 5 个区或 25 个键位筛选单字（按全码首码），集中练习某一键的码元与编码。
- **文稿跟打**：内置《小学生必备古诗 80 首》，可整首跟打；支持加载自定义 `.txt` / `.md` 文稿（UTF-8、GB18030）。加载后按最长词组优先预切分，单字自动采用最少击键的简码（一级/二级简码），当前词组或单字、编码、键位同步提示。古诗原文为公有领域作品，异文采用小学教材通行版本。
- **按难度分级**：一级简码、键名汉字、二级简码、三级简码、全码字，以及按字数划分的词组。
- **逐码判定**：输错不前进，必须重打当前字母；Backspace 可退回本字已输入的码；一级/二级/三级简码输入后可按空格直接提交。
- **编码提示**：完整编码 / 逐码提示（默认）/ 关闭提示。开启提示时，练习页右侧会从 `wubi98-table.png` 裁出当前键位的图形，关闭提示后自动隐藏。
- **实时统计**：进度、字/分、准确率、用时、连击与错误数。
- **虚拟键盘**：98 版 25 键位、区位号、键名与码元；当前应敲的键高亮，敲对/敲错闪烁反馈。
- **字根口诀**：首页显示 25 键完整助记口诀，练习时同步显示当前应敲键对应的口诀。
- **编码查询（双向）**：编码反查输入 1–4 位编码查询单字/词组；汉字查码输入汉字、词组或句子，按最长词组优先切分并给出最少击键编码与全码。结果点击可复制。
- **错题本**：结算页列出出错或跳过的字词，可一键重练。
- **最佳记录**：按练习模式分别保存，可清空。
- **扩展字库**：可选加载 `wubi98.large.txt` 中的扩展 A/B 区生僻字。
- **键位总图**：菜单中可直接查看项目自带的 98 版键位图。
- **跟随主题**：自动适配明暗模式，无额外主题依赖。

## 运行

依赖：Python ≥ 3.10、GTK ≥ 4.10、PyGObject。

```bash
# Debian / Ubuntu
sudo apt install python3-gi gir1.2-gtk-4.0

# 在仓库目录直接运行（需要同目录下的 wubi98*.txt）
python3 -m wubi98type
```

安装为命令：

```bash
pip install .
wubi98type
```

词库按以下顺序查找：

1. 环境变量 `WUBI98TYPE_DATA` 指向的目录；
2. 当前工作目录；
3. 仓库/安装包所在目录；
4. `~/.local/share/wubi98type/`。

只要目录中有 `wubi98.main.txt` 即可，它同时包含单字和词组编码。扩展字库需要 `wubi98.large.txt`。当前键位图形默认从同目录的 `wubi98-table.png` 裁剪，也可用 `WUBI98TYPE_TABLE` 直接指定图片路径。

## 使用

1. 在首页选择练习模式、范围、每组题数与提示方式。
2. 点「开始练习」，直接用英文键盘输入编码，不经过输入法。
3. 打满一个字/词的编码后自动跳到下一题。

键位专项：

1. 练习模式选择「键位专项」。
2. 练习范围可选「1 区 · 横（G F D S A）」等区级范围，也可选「A 键 · 15 工 · 工戈草头右框七」等单个键位。
3. 题目按单字全码的首码筛选，配合虚拟键盘和字根口诀集中练习该键。

文稿跟打：

1. 练习模式选择「文稿跟打」。
2. 练习范围中选择《小学生必备古诗 80 首》中的任意一首；或在「自定义文稿」中点「选择文本文件…」加载自己的 `.txt` / `.md` 文件。
3. 点击「开始跟打」，按顺序输入每段的五笔编码。词组按整词编码输入，单字自动提示最少击键的简码；标点、空格和换行不参与输入，当前段会整段高亮，文稿会随进度自动滚动。

编码查询：

1. 点击标题栏的搜索按钮，或菜单中的「编码查询」。
2. 窗口包含「编码反查」和「汉字查码」两个页签。
3. 编码反查：输入 1–4 位编码（a–y），例如 `a`、`khk`、`trng`，精确匹配在前，同前缀编码在后。
4. 汉字查码：输入汉字、词组或句子，例如 `的`、`北京`、`我爱北京天安门`；程序按最长词组优先切分，分别给出最少击键编码和全码。
5. 两页都可以点击结果或「复制」按钮复制编码/汉字。

快捷键：

| 按键 | 作用 |
| --- | --- |
| `a`–`y` | 输入编码（`z` 在 98 版中不作编码） |
| `Backspace` | 退回本字已输入的码 |
| `Space` | 输入简码后提交（一级/二级/三级简码等，按码表可用简码为准） |
| `Tab` | 跳过当前题（会记入错题） |
| `Esc` | 结束本组并查看成绩 |

设置和最佳成绩保存在 `~/.config/wubi98type/config.json`（遵循 `XDG_CONFIG_HOME`）。

## 分级说明

当前标准码表（`wubi98.main.txt`，单字与词组）包含：

| 范围 | 数量 |
| --- | ---: |
| 一级简码 | 25 |
| 键名汉字 | 24 |
| 二级简码 | 1,191 |
| 三级简码 | 7,195 |
| 全码单字 | 12,475 |
| 全部单字 | 20,911 |
| 双字词 / 三字词 / 四字词 / 多字词 | 59,032 / 6,899 / 9,424 / 583 |

单字取码表中最长的编码作为题组练习的全码；最短编码长度用作常用程度的近似（五笔简码本身按字频设置），因此二级简码都是高频字。文稿跟打则按最长词组优先切分，单字使用最少击键的简码，词组使用整词编码。

## 开发

```bash
# 单元测试（纯逻辑，无需图形环境）
python3 -m unittest discover -s tests -v
```

代码结构：

```
wubi98type/
  data.py        词库解析、分级、题目池
  drill.py       出题与判定状态机（可独立测试）
  encoding.py    汉字查码、最长词组切分、最少击键编码
  passage.py     文稿预处理、自定义文本读取、按段序列
  poems.py       小学生必备古诗 80 首
  config.py      设置与最佳成绩持久化
  keymap.py      98 版键位/码元数据、助记口诀
  keytable.py    从键位图裁剪当前键位图形
  lookup.py      编码反查索引与查询
  ui/
    home.py      首页
    practice.py  练习页
    summary.py   结算页
    keyboard.py  虚拟键盘（Cairo 绘制）
    lookup.py    双向编码查询窗口
    window.py    主窗口、快捷键、菜单
  style.css      GTK4 样式
tests/test_core.py
```
