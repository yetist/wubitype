# 五笔打字通

五笔打字通是基于 GTK4 的五笔 98 / 86 版打字练习软件。按所选版本的码表出题，实时判定编码，统计速度、准确率与错题，并配有可高亮当前按键的虚拟键盘。

## 功能

- **98 / 86 双版本**：首页可切换「五笔 98 版」和「五笔 86 版」，码表、键位码元、助记口诀、键位图、简码和成绩均按版本独立。
- **题组练习**：单字、词组、混合（70% 单字 + 30% 词组）。
- **键位专项**：按 5 个区或 25 个键位筛选单字（按全码首码），集中练习某一键的码元与编码。
- **文稿跟打**：内置《小学生必备古诗 80 首》和 42 篇练习文章，可整篇跟打；支持加载自定义 `.txt` / `.md` 文稿（UTF-8、GB18030）。加载后按最长词组优先预切分，单字自动采用最少击键的简码（一级/二级简码），当前词组或单字、编码、键位同步提示。古诗原文为公有领域作品，异文采用小学教材通行版本；内置文章版权归原作者所有，再分发前请确认授权。
- **按难度分级**：一级简码、键名汉字、二级简码、三级简码、全码字，以及按字数划分的词组。
- **逐码判定**：输错不前进，必须重打当前字母；Backspace 可退回本字已输入的码；一级/二级/三级简码输入后可按空格直接提交。
- **编码提示**：完整编码 / 逐码提示（默认）/ 关闭提示。练习中可通过主菜单「编码提示」实时切换，编码框和键位预览立即更新。开启提示时，练习页右侧会从当前版本的键位图（`wubi98-table.png` 或 `wubi86-table.png`）裁出当前键位的图形，关闭提示后自动隐藏。
- **实时统计**：进度、字/分、准确率、用时、连击与错误数。
- **虚拟键盘**：98 / 86 版 25 键位、区位号、键名与码元；当前应敲的键高亮，敲对/敲错闪烁反馈。86 版 Z 键显示为学习键。
- **字根口诀**：首页显示当前版本 25 键完整助记口诀，练习时同步显示当前应敲键对应的口诀。
- **编码查询（双向）**：编码反查输入 1–4 位编码查询单字/词组；汉字查码输入汉字、词组或句子，按最长词组优先切分并给出最少击键编码与全码。结果点击可复制。
- **错题本**：结算页列出出错或跳过的字词，可一键重练。
- **最佳记录**：按编码版本和练习模式分别保存，可清空。
- **扩展字库**：可选加载 `wubi98.large.txt` / `wubi86.large.txt` 中的扩展 A/B 区生僻字。
- **键位总图**：菜单中可直接查看当前版本自带的键位图，支持缩放、适应窗口、1:1、全屏和方向键滚动。
- **跟随主题**：自动适配明暗模式，无额外主题依赖。

## 安装与运行

依赖：Python ≥ 3.10、GTK ≥ 4.10、PyGObject。

Debian / Ubuntu：

```bash
sudo apt install python3-gi gir1.2-gtk-4.0
```

在源码树中直接运行：

```bash
PYTHONPATH=src python3 -m wubitype
# 或
PYTHONPATH=src ./data/wubitype
```

安装到系统（推荐，包含桌面菜单、图标、AppStream 元数据和 man 手册）：

```bash
meson setup build --prefix=/usr
sudo meson install -C build
wubitype
```

安装到用户目录：

```bash
meson setup build --prefix="$HOME/.local"
meson install -C build
```

也可以使用 pip 安装，码表会随 wheel 安装到对应前缀的 `share/wubitype`：

```bash
pip install .
wubitype
```

码表按以下顺序查找：

1. 环境变量 `WUBITYPE_DATA` 指向的目录；
2. 源码树 `data/` 或当前工作目录；
3. `XDG_DATA_DIRS` 下的 `wubitype/`（通常是 `/usr/share/wubitype/`）；
4. `~/.local/share/wubitype/`；
5. 当前 Python 前缀的 `share/wubitype/`。

目录中只要有 `wubi98.main.txt` 或 `wubi86.main.txt` 即可；标准码表同时包含单字和词组编码。扩展字库需要对应的 `wubi98.large.txt` / `wubi86.large.txt`。当前键位图形默认从同目录的 `wubi98-table.png` / `wubi86-table.png` 裁剪，也可用 `WUBITYPE_TABLE` 直接指定图片路径。

系统安装后的主要文件：

```
/usr/bin/wubitype
/usr/lib/python3.*/site-packages/wubitype/
/usr/share/wubitype/                 # 码表、键位图和内置文章
/usr/share/wubitype/text/            # 内置练习文章
/usr/share/applications/io.github.wubitype.WubiType.desktop
/usr/share/metainfo/io.github.wubitype.WubiType.metainfo.xml
/usr/share/icons/hicolor/scalable/apps/io.github.wubitype.WubiType.svg
/usr/share/man/man1/wubitype.1
```

设置和最佳成绩保存在 `~/.config/wubitype/config.json`（遵循 `XDG_CONFIG_HOME`）。

## 使用

1. 在首页「编码版本」中选择「五笔 98 版」或「五笔 86 版」。
2. 选择练习模式、范围、每组题数与提示方式。
3. 点「开始练习」，直接用英文键盘输入编码，不经过输入法。
4. 打满一个字/词的编码后自动跳到下一题。

练习过程中可随时打开主菜单 →「编码提示」，切换「完整编码 / 逐码提示 / 关闭提示」，当前题目的编码框和键位预览会立即更新。

结算页：

- 结算页默认焦点在「再来一组」；有错题时可按 `R` 重练错题。
- 按 `Enter` 再来一组，按 `Esc` 可直接返回首页。

键位专项：

1. 练习模式选择「键位专项」。
2. 练习范围可选「1 区 · 横（G F D S A）」等区级范围，也可选「A 键 · 15 工 · 工戈草头右框七」等单个键位。
3. 题目按单字全码的首码筛选，配合虚拟键盘和字根口诀集中练习该键。

文稿跟打：

1. 练习模式选择「文稿跟打」。
2. 练习范围中选择《小学生必备古诗 80 首》中的任意一首、内置练习文章，或在「自定义文稿」中点「选择文本文件…」加载自己的 `.txt` / `.md` 文件。
3. 点击「开始跟打」，按顺序输入每段的五笔编码。词组按整词编码输入，单字自动提示最少击键的简码；标点、空格和换行不参与输入，当前段会整段高亮，文稿会随进度自动滚动。

编码查询：

1. 点击标题栏的搜索按钮，或菜单中的「编码查询」。
2. 窗口包含「汉字查码」和「编码反查」两个页签。
3. 编码反查：输入 1–4 位编码（a–y），例如 `a`、`khk`、`trng`，精确匹配在前，同前缀编码在后。
4. 汉字查码：输入汉字、词组或句子，例如 `的`、`北京`、`我爱北京天安门`；程序按最长词组优先切分，分别给出最少击键编码和全码。
5. 两页都可以点击结果或「复制」按钮复制编码/汉字。

快捷键：

| 按键 | 作用 |
| --- | --- |
| `F1` | 快捷键帮助 |
| `F2` | 查看当前版本键位图 |
| `F3` | 循环切换编码提示 |
| `Ctrl+F` | 打开编码查询 |
| `Ctrl+Q` | 退出程序 |
| `a`–`y` | 输入编码（`z` 在 98 版中不作编码，86 版显示为学习键） |
| `Backspace` | 退回本字已输入的码 |
| `Delete` / `Ctrl+Backspace` | 清空当前字已输入的码 |
| `Space` | 输入简码后提交（一级/二级/三级简码等，按码表可用简码为准） |
| `Tab` | 跳过当前题（会记入错题） |
| `Ctrl+P` | 暂停 / 继续 |
| `Esc` | 结束本组并查看成绩；结算页返回首页 |
| `Ctrl+R` | 打字界面重新开始 |
| `R` | 结算页重练错题 |
| `Enter` | 结算页再来一组；编码查询复制当前结果 |
| `Ctrl+Enter` | 首页开始练习 |
| `F6` | 首页切换五笔 98 / 86 版 |
| `Ctrl+O` | 文稿跟打模式加载自定义文本 |
| `Ctrl+1` / `Ctrl+2` | 编码查询切换到汉字查码 / 编码反查 |
| `Ctrl+L` | 编码查询聚焦搜索框 |
| `↑` / `↓` | 编码查询浏览结果 |
| `Ctrl+C` | 编码查询复制当前结果 |
| `Esc` / `Ctrl+W` | 关闭键位图 |
| `F11` | 键位图全屏 |
| `+` / `-` | 键位图放大 / 缩小 |
| `0` / `1` | 键位图适应窗口 / 实际大小 |
| `↑` / `↓` / `←` / `→` | 键位图滚动 |

> `R` 本身是五笔编码键（32 R），为避免影响正常输入，重新开始使用 `Ctrl+R`。

## 分级说明

两个版本的标准码表（`data/wubi98.main.txt` / `data/wubi86.main.txt`，均包含单字与词组）包含：

| 范围 | 98 版 | 86 版 |
| --- | ---: | ---: |
| 一级简码 | 25 | 25 |
| 键名汉字 | 24 | 25 |
| 二级简码 | 1,191 | 648 |
| 三级简码 | 7,195 | 7,870 |
| 全码单字 | 12,475 | 12,304 |
| 全部单字 | 20,911 | 20,910 |
| 双字词 | 59,032 | 50,150 |
| 三字词 | 6,899 | 5,800 |
| 四字词 | 9,424 | 10,329 |
| 多字词 | 583 | 696 |

单字取码表中最长的编码作为题组练习的全码；最短编码长度用作常用程度的近似（五笔简码本身按字频设置），因此二级简码都是高频字。文稿跟打则按最长词组优先切分，单字使用最少击键的简码，词组使用整词编码。
