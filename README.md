# 五笔 98 打字练习

用 GTK4 写的五笔字型 98 版打字练习器。按 98 版码表出题，实时判定编码，统计速度、准确率与错题，并配有一张可高亮当前按键的虚拟键盘。

## 功能

- **三种练习模式**：单字、词组、混合（70% 单字 + 30% 词组）。
- **按难度分级**：一级简码、键名汉字、二级简码、三级简码、全码字，以及按字数划分的词组。
- **逐码判定**：输错不前进，必须重打当前字母；Backspace 可退回本字已输入的码。
- **编码提示**：完整编码 / 逐码提示（默认）/ 关闭提示。
- **实时统计**：进度、字/分、准确率、用时、连击与错误数。
- **虚拟键盘**：98 版 25 键位、区位号、键名与码元；当前应敲的键高亮，敲对/敲错闪烁反馈。
- **字根口诀**：首页显示 25 键完整助记口诀，练习时同步显示当前应敲键对应的口诀。
- **错题本**：结算页列出出错或跳过的字词，可一键重练。
- **最佳记录**：按练习模式分别保存，可清空。
- **扩展字库**：可选加载 `wubi98.large.txt` 中的扩展 A/B 区生僻字。
- **键位总图**：菜单中可直接查看项目自带的 98 版键位图。
- **跟随主题**：自动适配明暗模式，无额外主题依赖。

## 运行

依赖：Python ≥ 3.10、GTK ≥ 4.10、PyGObject。

```bash
# Debian / Ubuntu
sudo apt install python3-gi gir1.2-gtk-4.0

# 在仓库目录直接运行（需要同目录下的 wubi98*.txt）
python3 -m wubi98type
```

安装为命令：

```bash
pip install .
wubi98type
```

词库按以下顺序查找：

1. 环境变量 `WUBI98TYPE_DATA` 指向的目录；
2. 当前工作目录；
3. 仓库/安装包所在目录；
4. `~/.local/share/wubi98type/`。

只要目录中有 `wubi98.single.txt` 即可。扩展字库需要 `wubi98.large.txt`，词组需要 `wubi98.main.txt`。

## 使用

1. 在首页选择练习模式、范围、每组题数与提示方式。
2. 点「开始练习」，直接用英文键盘输入编码，不经过输入法。
3. 打满一个字/词的编码后自动跳到下一题。

快捷键：

| 按键 | 作用 |
| --- | --- |
| `a`–`y` | 输入编码（`z` 在 98 版中不作编码） |
| `Backspace` | 退回本字已输入的码 |
| `Tab` | 跳过当前题（会记入错题） |
| `Esc` | 结束本组并查看成绩 |

设置和最佳成绩保存在 `~/.config/wubi98type/config.json`（遵循 `XDG_CONFIG_HOME`）。

## 分级说明

当前标准码表（`wubi98.single.txt` + `wubi98.main.txt`）包含：

| 范围 | 数量 |
| --- | ---: |
| 一级简码 | 25 |
| 键名汉字 | 24 |
| 二级简码 | 1,191 |
| 三级简码 | 7,195 |
| 全码单字 | 12,475 |
| 全部单字 | 20,911 |
| 双字词 / 三字词 / 四字词 / 多字词 | 59,032 / 6,899 / 9,424 / 583 |

单字取码表中最长的编码作为练习全码；最短编码长度用作常用程度的近似（五笔简码本身按字频设置），因此二级简码都是高频字。

## 开发

```bash
# 单元测试（纯逻辑，无需图形环境）
python3 -m unittest discover -s tests -v
```

代码结构：

```
wubi98type/
  data.py        词库解析、分级、题目池
  drill.py       出题与判定状态机（可独立测试）
  config.py      设置与最佳成绩持久化
  keymap.py      98 版键位/码元数据
  ui/
    home.py      首页
    practice.py  练习页
    summary.py   结算页
    keyboard.py  虚拟键盘（Cairo 绘制）
    window.py    主窗口、快捷键、菜单
  style.css      GTK4 样式
tests/test_core.py
```
